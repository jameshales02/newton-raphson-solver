Prop account risk model

Monte Carlo of a futures strategy against evaluation rules: trailing drawdown, daily loss limit, target and time limit. Gives the odds of passing or blowing up at each size.

  • 54%best pass rate, at 2 contracts; bigger sizes approach a coin toss
  • ±1.5 ptsagreement with the overshoot-corrected gambler's ruin

Runs where you read it

Every engine is a plain JavaScript module with no build step, running in your browser. The same files are imported by the test suite, so the demo is the tested code. The data pipeline's Python and browser halves execute identical SQL files.

Tested, not just plotted

59 JavaScript tests (npm test) and 19 Python tests check rules exactly, compare optimised code against naive references, and verify statistics against closed forms. Continuous integration runs both on every push.

Honest maths

Each page writes out the formulas it implements, reports standard errors next to estimates, and ends with its limitations. Where a result disagreed with theory or with a published paper, the page says by how much and why.
